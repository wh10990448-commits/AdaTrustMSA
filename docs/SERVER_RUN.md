## 环境与训练

- GPU：NVIDIA GeForce RTX 4090，24,564 MiB；
- 服务器实际内存：251 GiB，运行后可用约 232 GiB；
- 本次训练环境：PyTorch 2.0.1+cu117、Transformers 4.41.2；
- 原浅融合参数：11,338,650；默认深融合参数：11,608,273；
- batch size：48；
- 原浅融合运行 17 个 epoch，耗时 406.54 秒，最佳 epoch 9、验证分数 0.689860；
- 默认深融合运行 18 个 epoch，耗时 507.59 秒，最佳 epoch 10、验证分数 0.690982。
- 深融合 + CQPA 运行 18 个 epoch，耗时 517.95 秒，最佳 epoch 10、验证分数 0.692097；参数量仍为 11,608,273。

代码同时保留 PyTorch 2.8 / Transformers 4.57 的固定依赖；本次服务器使用已有 CUDA 环境的兼容路径，并通过完整单元测试、模型冒烟测试及真实 GPU 矩阵运算测试。
